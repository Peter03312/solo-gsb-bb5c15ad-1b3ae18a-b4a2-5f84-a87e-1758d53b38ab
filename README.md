# WebVTT 字幕校时台

本地运行的 WebVTT 字幕时间轴校对工具。可导入或粘贴 WebVTT，在与视频同步的时间轴上直接拖动字幕块与起止边界，支持自动吸附、连锁传播、撤销/重做，并导出修复后的 VTT。

技术栈：**React 18 + TypeScript + Vite**，纯前端实现，字幕与视频均在浏览器本地处理，不上传任何数据。

## 功能

- **导入 / 粘贴 VTT**：支持文件选择或直接粘贴 WebVTT 文本，容错解析（自动忽略 NOTE/REGION/STYLE 块，按起点排序）。
- **视频同步**：加载本地视频（可选），播放头实时映射到时间轴；点击标尺跳转，空格键播放/暂停。
- **拖拽校时**
  - 拖动字幕块整体平移；拖动左右边缘调整起点/终点。
  - **100ms 内自动吸附**播放头或任意相邻字幕的起止边界，显示黄色吸附指示线。
  - 时间轴可缩放（10–320 px/秒），拖动到边缘自动横向滚动。
- **连锁模式**（默认开启）
  - 拖出的重叠量逐条向相邻字幕传递（波纹推进），被推动的字幕保持时长。
  - 任意情况下始终保证：起点 `≥ 0`、每条时长 `≥ 300ms`、所有字幕互不重叠。
  - 关闭连锁模式时，字幕块会被相邻边界直接挡住。
- **字幕列表**：精确编辑时间戳与文本、单条新增/删除/拆分；正在播放的字幕高亮。
- **字幕拆分**：在字幕列表点「✂ 拆分」（表头按钮作用于选中条，行内按钮作用于该行），输入切点 N 后实时预览两段正文与时间。N 按**可见 Unicode 码点**计数：换行计 1 字；WebVTT 命名实体（`&amp;`）与数字实体（`&#65;`/`&#x41;`）各计 1 字并原样保留；标签不计。支持正确嵌套的 `b/i/u/c/v/lang` 标签，切点处未闭合的标签在左段按嵌套逆序闭合、在右段原样重开；未知或不配对标签、内联时间戳（`<00:00:01.000>`）会报错并禁止应用。分割时间 = 原起点 + 原时长 × N / 总字数（四舍五入到毫秒），两段首尾相接、保留原起止，任一段不足 300ms 禁止应用。确认后用两条新 id 字幕替换原条（其余字幕不变），一次撤销/重做即可恢复整次拆分，列表、时间轴与 VTT 导出同步更新。
- **字幕自动换行**：在字幕列表点「⏎ 换行」（表头按钮作用于选中条，行内按钮作用于该行），为单条字幕设置每行最大显示列数，实时预览后可应用为最多两行。列数按 **Unicode 显示宽度**计：宽字符/全角计 2 列，组合符/格式符计 0 列；WebVTT 实体（`&amp;`、`&#x4E2D;`）作为一个可见字符、按所代表字符计列并原样保留；内联标签不计列且原样保留。只在原文空格或标点边界选断点（连续空白整段替换为换行；连续标点在其后断行），以「两行最长宽度最小、再宽度差最小」确定唯一断点（仍并列取最靠前者）。找不到满足上限的断点时说明原因并禁止应用；已有换行的字幕不自动改写。应用只改该条正文（id 与起止时间不变），一次撤销/重做即可恢复，导出 VTT 保留换行结果。
- **剪辑版本时间映射**：输入至少 2 组「旧版时间 → 新版时间」锚点（两侧均须严格递增），按相邻锚点分段线性映射每条字幕的起止点，区间外按最近一段斜率外推；提交前逐条预览新时间，若出现负起点、时长不足 300ms 或相邻重叠会标出受影响字幕并禁止应用；通过后一次性替换全部时间（保留文本与 id），可撤销/重做。
- **术语审校**：维护「原词 → 推荐词」替换规则（两者均须非空、原词不可重复，整行留空可忽略）。按字幕正文中的可见文本做**区分大小写的字面匹配**；WebVTT 内联标签（如 `<b>`、`<00:00:01.000>`）与实体（如 `&amp;`）作为边界原样保留、不参与匹配。同一位置多条规则命中时取最长原词，等长按规则顺序；已匹配的字符不再重复匹配。逐条预览命中位置、原文与替换后正文（命中处高亮），可勾选要应用的字幕；确认后仅替换所选字幕文本（时间与 id 不变），一次应用只产生一条撤销历史，导出 VTT 随之反映结果。
- **撤销 / 重做**：`Ctrl+Z` 撤销，`Ctrl+Shift+Z` / `Ctrl+Y` 重做；一次拖拽、一次版本映射、一次术语替换、一次拆分或一次换行只产生一条历史。
- **导出**：一键下载修复后的 `fixed-subtitles.vtt`，或复制到剪贴板（保留原始 cue id）。

## 一条命令启动（Docker Compose）

无需任何额外配置（纯前端应用，字幕与视频均在浏览器本地处理）：

```bash
docker compose up --build -d
```

启动后在浏览器访问：

> **http://localhost:8080**

唯一可选配置是宿主机端口（默认 8080，通过环境变量 `WEBVTT_PORT` 覆盖）：

```bash
WEBVTT_PORT=9000 docker compose up --build -d
```

停止：

```bash
docker compose down
```

## 本地开发（无 Docker）

要求 Node.js 18+。

```bash
npm install
npm run dev
```

访问终端输出的地址（默认 http://localhost:5173 ）。

生产构建与本地预览：

```bash
npm run build
npm run preview
```

## 使用说明

1. 打开页面后点击「导入 VTT」选择 `.vtt` 文件或粘贴内容；也可以点「载入示例」快速体验。
2. （可选）点击视频区加载本地视频文件。
3. 在时间轴上拖动字幕块或其左右边缘；靠近播放头/相邻边界时会自动吸附。
4. 用顶栏开关切换连锁模式；`Ctrl+Z / Ctrl+Shift+Z` 撤销重做。
5. （可选）点击顶栏「版本映射」：输入至少 2 组旧版→新版时间锚点，预览每条字幕的新时间；有问题（负起点/时长不足/重叠）的行会标红并禁止应用，调整锚点后预览自动重算；确认无误后点「应用映射」一次性替换全部时间。
6. （可选）点击顶栏「术语审校」：维护「原词 → 推荐词」规则（均须非空、原词不重复），下方实时预览每条命中字幕的命中位置、原文与替换后正文；勾选要应用的字幕后点「应用替换」，仅改写所选字幕的文本（时间与 id 不变），可用 `Ctrl+Z` 一次撤销。
7. （可选）在字幕列表选中一条字幕后点「✂ 拆分」（或直接点行内 ✂）：输入切点 N（第 N 个可见字之后断开），弹窗实时预览两段正文与起止时间；含非法标签或任一段不足 300ms 时禁止应用。确认后原条被两条新 id 字幕替换，`Ctrl+Z` 一次撤销整次拆分。
8. （可选）在字幕列表选中一条字幕后点「⏎ 换行」（或直接点行内 ⏎）：输入每行最大显示列数，弹窗实时预览两行正文与各自列数；列数按 Unicode 显示宽度计（宽字符 2 列、实体按所代表字符计、标签不计），断点只取原文空格或标点边界。找不到满足上限的断点时会说明原因并禁止应用；已有换行的字幕不自动改写。确认后仅该条正文变为最多两行（id 与起止时间不变），`Ctrl+Z` 一次撤销。
9. 完成后点击「导出 VTT」下载，或「复制」取用文本。

## 项目结构

```
src/
  lib/
    engine.ts   # 校时引擎：连锁传播、不变量保证、100ms 吸附
    remap.ts    # 剪辑版本时间映射：锚点校验、分段线性映射/外推、预览与问题检测
    terms.ts    # 术语审校：规则校验、标签/实体边界、最长优先字面匹配、预览与应用
    split.ts    # 字幕拆分：可见字数统计、标签校验、切点闭合/重开、时间与 300ms 检查
    wrap.ts     # 自动换行：Unicode 显示宽度计列、空格/标点断点、唯一选点、最多两行
    vtt.ts      # WebVTT 解析与序列化
    time.ts     # 时间戳解析/格式化、常量（300ms、100ms）
  hooks/
    useUndoable.ts  # 撤销/重做历史栈（支持拖拽批次与文本编辑合并）
  components/
    Timeline.tsx    # 时间轴：拖拽、缩放、标尺、播放头、吸附指示
    CueTable.tsx    # 字幕列表精确编辑（含拆分、换行入口）
    VideoPlayer.tsx # 本地视频加载与同步
    ImportModal.tsx # VTT 导入/粘贴弹窗
    RemapModal.tsx  # 剪辑版本时间映射弹窗（锚点编辑 + 逐条预览）
    TermModal.tsx   # 术语审校弹窗（规则维护 + 命中预览与勾选）
    SplitModal.tsx  # 字幕拆分弹窗（切点输入 + 两段预览）
    WrapModal.tsx   # 自动换行弹窗（每行最大列数输入 + 两行预览）
  App.tsx
```
